# Tutorial – Create a Website with AI 🤖💻

## From Idea → ChatGPT → VS Code → GitHub Copilot → GitHub Pages

### Introduction

In this tutorial, you will learn how **Generative AI tools** can help you create and improve a website.

We will create a simple pizza café website called:

# 🍕 Pizza Palace

You will use:

* **ChatGPT** – to generate the initial website
* **VS Code** – to edit and test the website
* **GitHub Copilot** – to modify and improve the code
* **GitHub** – to store your project
* **GitHub Pages** – to publish your website online

> **Important:** AI is a tool to help you create websites. Always read, test and understand the code instead of blindly copying it.

---

# Part 1 – Create Your Website Using ChatGPT

## Step 1 – Open ChatGPT

Open ChatGPT and start a new conversation.

We will give ChatGPT a detailed prompt describing the website we want.

---

## Step 2 – Enter the Prompt

Copy and paste the following prompt into ChatGPT:

```text
Create a complete responsive website called "Pizza Palace", a modern pizza café.

Target audience: teenagers and families.

Use:
- HTML5
- Bootstrap 5
- Bootstrap Icons
- Google Fonts

Important requirements:
- Maximise the use of Bootstrap 5 classes.
- Keep custom CSS to an absolute minimum.
- Do not use external CSS frameworks other than Bootstrap.
- Use Bootstrap containers, rows, columns, cards, buttons, alerts and navbar classes wherever possible.
- Make the website responsive for mobile, tablet and desktop.
- Use Bootstrap grid classes such as col-lg-4 col-md-6 col-12.
- Use attractive images from Unsplash.
- Use Bootstrap Icons wherever appropriate.

Create these sections:

1. Responsive Navbar
   - Pizza Palace logo/name
   - Home
   - Menu
   - About
   - Contact

2. Hero section
   - Large heading: "Fresh Pizza. Happy Moments."
   - Short description
   - "View Menu" button
   - Attractive pizza image

3. Popular Pizzas
   - Three Bootstrap cards
   - Margherita
   - BBQ Chicken
   - Veggie Supreme
   - Each card should have an image, title, description, price and button.
   - Cards should have equal height.

4. Why Choose Us
   - Three simple features using Bootstrap Icons:
     Fresh Ingredients
     Fast Delivery
     Great Taste

5. Special Offer
   - Use a Bootstrap alert.
   - Display: "Get 20% OFF on your first order!"

6. Contact section
   - Name
   - Email
   - Message
   - Submit button

7. Footer
   - Copyright message
   - Social media icons

Use semantic HTML elements such as header, nav, main, section and footer.

Use Bootstrap utility classes extensively for spacing, alignment, colors, typography, shadows and responsiveness.

Keep the code beginner-friendly and well commented.

Return the complete HTML file in one code block.
```

# Part 2 – Create the Project in VS Code

## Step 3 – Create a Project Folder

Create a folder called:

```text
pizza-palace
```

Open this folder in **VS Code**.

---

## Step 4 – Create `index.html`

Inside the folder, create:

```text
pizza-palace/
└── index.html
```

Copy the HTML code generated by ChatGPT and paste it into `index.html`.

Save the file.

# Part 4 – Ask ChatGPT to Improve the Website

Your first version doesn't have to be perfect.

This is where **prompting** becomes important.

Instead of asking:

```text
Make my website better.
```

give ChatGPT a specific instruction.

---

## Step 6 – Improve the Hero Section

Ask ChatGPT:

```text
Improve only the Hero section of the Pizza Palace website.

Make it more visually attractive using Bootstrap 5 classes.

Requirements:
- Use Bootstrap classes as much as possible.
- Do not add custom CSS unless absolutely necessary.
- Make the heading large and bold.
- Add a short attractive tagline.
- Add two buttons: "View Menu" and "Order Now".
- Improve spacing and alignment.
- Keep it responsive.

Return only the modified Hero section.
```

Copy the modified section and replace the old Hero section in your HTML.

Save and refresh the browser.

# Part 8 – Introduce GitHub Copilot

Now we will use another AI tool.

**GitHub Copilot** can assist you while you are writing and modifying code in VS Code.

The difference is:

```text
ChatGPT
   ↓
Ask AI for code or ideas
```

while:

```text
GitHub Copilot
   ↓
AI assistance directly inside VS Code
```

---

# Part 12 – Save Your Project to GitHub

Once you are happy with your website, save your project to GitHub.

Open **Source Control** in VS Code.

### Step 1 – Stage Changes

Click:

**Source Control → `+`**

or **Stage All Changes**.

---

### Step 2 – Commit

Enter:

```text
Created Pizza Palace website using AI
```

Click:

**Commit**

---

### Step 3 – Push

Click:

**Sync Changes** or **Push**

Your updated website will now be uploaded to GitHub.

---

# Part 13 – Publish Your Website

If GitHub Pages has already been configured for your repository, your website will be published automatically after the changes are pushed.

Your website URL will look similar to:

```text
https://yourusername.github.io/pizza-palace/
```

Open the URL in your browser.

🎉 **You have created and published an AI-assisted website!**

# 🧠 Remember

### Don't just ask:

> "Create a website."

Instead, tell AI:

> **What** you want
> **How** it should look
> **Which technology** to use
> **What restrictions** to follow

For this course, an excellent instruction to remember is:

> **"Maximise the use of Bootstrap 5 classes and keep custom CSS to a minimum."**

And most importantly:

**AI can write code for you, but you should still be the designer and decision-maker.**
